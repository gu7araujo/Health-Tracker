1. Import Foundation only
2. Create actor NotificationPermissionManager (actor for thread safety)
3. Add private static constant: hasRequestedKey = "hasRequestedNotificationPermission"
4. Implement static func requestIfFirstLaunch() async:
   - Check UserDefaults.standard.bool(forKey: hasRequestedKey)
   - If true, return early (already requested)
   - Create NotificationService() instance
   - Create RequestNotificationPermissionUseCase(notificationService:) instance
   - Call try await useCase.execute() in do-catch
   - Log result: "Notification permission: \(granted ? "granted" : "denied")"
   - On catch: Log "Failed to request notification permission: \(error)" but DON'T crash
   - Set UserDefaults.standard.set(true, forKey: hasRequestedKey) regardless of result
   - Set delegate: notificationService.setDelegate(nil) for now (Phase 2 will add actual delegate)

**Critical:** Graceful degradation on errors (NOTIF-03). Permission denial or errors must NOT crash app. Use actor for thread-safe UserDefaults access.
